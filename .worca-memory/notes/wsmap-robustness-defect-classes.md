## Totality (scripts, detectors, routes, UI)
- `oneLine()` is not markdown-safe: a value starting a line opens a block (`# X`, `## Coverage`, a lone ``` or `<!--`, `---`, `- x`, `1. x`, `[x]: url`). Audit with `marked.lexer`; escape only real block starts (`3.0 API` stays).
- Mid-line HTML: DOMPurify (`ask-markdown.mjs`) drops an inline `<style>`/`<textarea>`/`<title>` WITH every later section. Escape `<` but leave odd backslash runs (`(?<!\\)((?:\\\\)*)<`), write `&lt;` inside URL runs, escape AFTER redaction; `noTag` is not compositional (escape the joined `file:line` once). Probe via `createMarkdownRenderer` under jsdom (<= 5000 renders per process).
- Agent briefs are markdown: collapse line breaks in every repo-written value a brief interpolates (`surveyBrief`, `synthBrief`, `usageBriefs` raw/file/reason) and in checker CLI output.
- Plain objects keyed by repo/agent strings (`aliasIndex['constructor']`, `REF_FLAG`, `(kinds[k] ||= []).push`, `byKind[k] + 1`): `Object.create(null)`, `Map`, `Object.hasOwn`; `JSON.parse` makes `__proto__` an own key. Member keys `<slug>-<8hex>` are safe.
- `(x || [])` is no array guard; `String(v)`/`${v}` throws on `{"toString":null}` (one corrupt `map_json` killed the workspace list): coerce `typeof v === 'string' ? v : typeof v === 'number' ? String(v) : ''`. `check*` were total; code trusting code-made docs was not.
- `createFileCache` keyed by absolute path only: key by `(root, abs)`. `changeOrder` uses iterative Tarjan (recursion overflows near 5 000 members).

- Random passwords beat hand-picked shapes: 3 000 per alphabet (base64; symbols incl. backtick `<>{}$@`; `[A-Za-z0-9!@#$%^&*]`; SQL Server `[A-Za-z0-9@!]`; `/` and `; , ) }`; `=`, `?`, `&`; users holding `@`) in postgres, http and templated JDBC URLs; canary = every 6-char window; diff previous vs current tree per template. Scan JSON pieces citing the file plus a global 6-gram index; one-char probes pin the leaking characters. Drop-one mutation appliers anchor on text present with or without the other fixes.
