## Hand-copied field lists
- A per-node field reaches a spawn only through FOUR hand-listed copies: `resolveGraph` node ctx → manifest cell (`buildGraphManifest`) → `orchestrator._execCtx`'s `node: {…}` literal (what `ctx.node` really is) → `resolvedFromManifest` (resume). A missing line in the last two is silently `undefined` (`subagentModel` has the gap). Pin `_execCtx` via `createOrchestrator({projectDir: <fresh git repo>, prompt:'x', auto:true, claude:{mock:true}})` with stubbed `orch.pipeline`/`orch.resolved`, then `orch._execCtx(node, resolved.nodes.<id>, {executionId:'x:<id>:1', ordinal:1})`; resume via `resolvedFromManifest(buildGraphManifest(…), registry).nodes.<id>.<field>`.
- `ctx.script` is hand-copied twice (`_execCtx` and `test/helpers/graph-run.mjs`): only `createOrchestrator({claude:{mock:true}, scriptsDir})` (`orchestrator-graph-script`) and `runGraphOffline` pin them — mutation-check both.
- Registry meta rides `ctx.meta` (top level), never `ctx.node.meta` (prove via `GraphOrchestrator.prototype._execCtx.call(fakeThis, tplNode, nc, {executionId})`). A user-layer sidecar lives in `$WORCA_HOME/.worca-cc/agents` (`$WORCA_HOME/agents` loads nothing).

## Prompt blocks and injected text
- A new prompt block renders from ctx DATA only (never IO or the ordinal alone): `buildAgentPrompt` is pure and three pins rebuild it from a bare ctx — `graph-executor` test 17, `claude-argv-snapshot` (scrubs to `<PROMPT>` only when equal) and 16 `prompt-snapshots` (verifier ctx ordinal 2 WITH a verdict). Put the data on the ctx in `_execCtx` (and `graph-run.mjs`) and gate the block on it. Changing `VERDICT_CONTRACT` or a sidecar's `promptHints` = `UPDATE_PROMPT_SNAPSHOTS=1` (5 files for the contract, 1 per hint); `graph-prompt-parity.test.mjs:78-111` pins v1 hint SENTENCES verbatim. `reviews` holds the NORMALIZED verdict; `human-evidence` sizes a raw verdict by its FIRST array key — keep `issues` first.
- Those pins never see a REAL spawn's prompt: capture one (~20 s) with a driver OUTSIDE the tree, sandbox homes + `WORCA_MOCK=1` + a failing fake `claude` on PATH, `executor.mjs` `_testing.runClaude = (o) => (cap.push(o.prompt), runClaude(o))`, `createOrchestrator({…, auto:true, claude:{mock:true}}).run()` (wf_default mock: refiner x2, reviewer x2; `MOCK_CYCLE`/`MOCK_ROLE` identify prompts).
- Text executor.mjs injects (`VERDICT_CONTRACT`, blocks gated on `verdict && ordinal > 1`) reaches ALL nine verdict agents: producers refiner, deckNarrative; verifiers planReviewer, reviewer, workspaceReviewer, manualWebUiTesting, deckAudit, deckExport, deckReviewer. Producer-only guidance there ("start from this record", "do not widen the audit") misleads every verifier (the deck reviewer must reopen every screenshot, the web-UI tester re-test): keep injected text role-neutral, put scope rules in the agent body or branch on `meta.runnerType`; grep `grep -l '"verdict"' agents/*.meta.json` bodies for conflicts.
- A new `## Severity rubric` leaves old severity sentences in "What to do" bullets ("Missing or fake tests are at least a major issue"): `grep -n 'at least a major\|is critical\|is major' agents/<f>.md .claude/agents/<f>.md` and reconcile; `agent-contract-sync` compares only shared sections.

## Resume, staging, mock
- Resume mixes two ages: PORTS from the frozen manifest, agent BODY + tools reloaded — refuse when the manifest lacks a needed node, or validate output before persisting. A resumed execution reuses its paths: clear output/verdict paths before each (re-)run.
- `_afterExecution` intent-to-adds (`git add -A -N`) for `sideEffect:'code'` agents (mock runs show NEW files in `git diff <checkpoint>`); `_stageWorkingTree({ignoreAbort:true})` survives stop.
- On a mock run a script card with no `mock` runs for REAL while upstream mock agents write `{"mock": true, …}` JSON: runner-side validation of upstream JSON degrades to a warning under `mockEnabled(ctx.claudeOpts)`.

## Spawning children (script runner, probes)
- macOS child `process.cwd()` is `/private/var…`, not the mkdtemp path: compare realpaths or assert `ctx.cwd`. Windows `cmd.exe /d /s /c` needs outer quotes + `windowsVerbatimArguments: true`.
- The host process is at stake: always `child.stdin.on('error', () => {})` (EPIPE kills the SERVER); tree-kill even when the direct child exited (`sh -c "x &"`): signal `-pid` + a post-kill grace destroying our pipes; track `detached:true` children and `killTree` from a sync `process.on('exit')`.
- A new child kind's env = `buildSpawnEnv(...)` over `scrubbedEnv(platform)` (`_execCtx` hands `claudeOpts.envScrub/envAllowlist`).
- `buf += chunk; while ((i = buf.indexOf('\n')) >= 0)` is QUADRATIC on newline-free output: scan each chunk once, bound the partial line (64 KiB) and every whole-stdout accumulator (a probe on `/usr/bin/yes` took the server down: cap 4 KiB, kill early, pin it). `setTimeout` > 2^31-1 ms fires after 1 ms: clamp in normalizer, graph rule and spawn site.
- A timer bounding an exit flush starts FROM the write callback (`outWrite(text, () => { setTimeout(bye, 1000); errWrite('', bye); })`, writers bound before importing the user program). Probe cwd ≠ run cwd: make relative `WORCA_PYTHON`-style paths absolute. A cached async probe never rejects (express 4 has no async catch).
- Python harness (`worca_script.py`): `keep = os.dup(1)` (non-inheritable), `os.dup2(2, 1)`, frame to `keep`; `sys.dont_write_bytecode = True` in code; `ast.parse(src, file, feature_version=(3, 8))`; `json.dumps(…, allow_nan=False)` → a `frame is not serializable` frame; load via `SourceFileLoader` into a `types.ModuleType` in `sys.modules`. Open: fixed module name vs multiprocessing spawn, program dir first on `sys.path`, non-daemon threads, only `error.message` reaches the run.

## Fixtures and small pins
- Raw fixture metas never trigger V9 (`portsFnFor(AGENTS, {})` passes metas as-is; V9 needs a truthy `required`): put `required: true` on fixture inputs and assert the precondition; pin the `had` filter with a persisting real error (unknown-key V4). `incomplete` is set on V9, V20, V21, V22 and V4 ports-missing.
- `test/graph-validate.test.mjs` `ok()` already wires `n_rev.review → n_impl.fix`; a blocking wire closing a cycle is a loop wire. A test's switch must not be a substring of its command. A "no `shell: true`" grep hits comments. Renaming a dir: grep quoted segments too.
- `classifyLoops` needs the SOURCE port's registry (a ports function without scripts drops a loop's max-cycles row; `panelPortsFn` falls back to `gvPortsFn` on warm pages): a function gaining a registry parameter → grep every caller and wrapper (`ask-panel.mjs` `workflowDesc`, `ask/catalog.mjs`, `node-tunables.mjs`).
- `graph-scheduler` test 15 pins an exec event's key set; `bandOf` is for `kind === 'agent'` only; `geometry.mjs` does not import `constants.mjs` (`flow-layout.mjs`/`workflows.mjs` do, for `KEYED_KINDS`); `PLUGIN_FILES` is shared across plugins in one `WORCA_HOME`; `ui/server.mjs`'s `fs` is sync.
- New node KIND that waits (a person): neither FLOW (`fireFlow` awaits inline, freezing the drain walk) nor KEYED (key + pool slot) — fire it like an agent with no slot. V9 skips non-keyed kinds; a non-`blocking` exit closing a cycle needs V10 + layout cuts (else End ranks column 0). `ask-composer-api.test.mjs:63` builds `n_${kind}${i}`: a hyphenated kind fails `NODE_ID_RE`.
- `shared-graph-purity` scans RAW `src/shared/**`: import specifiers (even in comments/strings) stay relative inside `src/shared`; code may not hold `['"]node:`, `process.`, `require(`, `fetch(`, `import.meta`, top-level `let`/`var`, or the words `window|document|navigator|localStorage`. It stops at the first failing file: prove a new file with its regexes in `node -e`; add new `src/shared/graph/*.mjs` to `shared-graph-single-source`.
