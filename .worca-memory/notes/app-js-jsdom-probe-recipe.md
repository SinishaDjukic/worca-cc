## Out-of-tree probe (~5 scenarios in ~5 s, one Bash call)
mktemp dir + `WORCA_HOME=$(mktemp -d)`; jsdom via `createRequire(S + '/package.json')('jsdom')` (needs a real `node_modules`); import `pathToFileURL(S + '/ui/public/app.js').href + '?b=' + Math.random()` per scenario. Lift `boot()` from `test/ui-workspace-wizard.test.mjs`: a `WSStub` whose `deliver(obj)` feeds `message` listeners, `window.fetch` over a MUTABLE list, `localStorage` keys set BEFORE import (`worca-cc.runTarget`, `worca-cc.lastWorkspace`), `location.hash` + `hashchange`, ~10 `setTimeout(0)` ticks, `process.exit(0)`. In-flight: `hold ? hold.then(() => json(…)) : json(…)`. Override fetch after boot via `globalThis.fetch = window.fetch = …`.

## Routing
- A `go()` that sets the hash AND dispatches `hashchange` routes twice; the second `showView` repaints what an async route forgot. Pin "repaints after the route loads" with ONE plain hash write and mutation-check the repaint.
- A view entry that awaits, then routes, needs a staleness guard (`enterWorkflowsView` undid a "+ New agent" hop and rewrote `#runs` → `#workflows`): take a module seq on entry and every route call, return after EACH await unless `seq === latest && currentShownView === '<x>'` (`wfvRouteStale`; precedent `workspacesLoadToken`). Pin with a fetch hold `{stop(), release()}` (never restore the global from inside); the entry's own `++seq` dies only by leave + return mid-load with the first entry resolving first.
- A hello'd FINISHED run with a History row never shows the run page (`#running/<id>` lands on `#history/<key>/<id>/details`): answer `/api/history` `{pipelines:[]}` or hello it `running`. Boots load no `style.css`: assert rules by regex on the file (`ui-new-run-folder`).
- jsdom focuses elements inside a HIDDEN view (Chrome no-ops): never pin "focus never moves into the hidden page" (red at base); pin "never `<body>`". To see the body drop, patch `HTMLElement.prototype.focus` to return early under `[hidden], .hidden`. Recurring class: a dialog open across an in-page tab switch focuses back into the hidden panel → `<body>`; `onClose` first focuses a shown control (`add-dialog.mjs`).
- Throws inside DOM listeners never fail a test (jsdom routes them to window `error`): after `boot()` collect `window` `error` messages and assert `[]`; grep a surviving listener mutant's log for `TypeError`. jsdom never blurs a button turning `disabled`: after `click()` focus a temporary button and remove it.
- "This hop fetches nothing": every `showView` fetches `/api/counts` (+ debounced `/api/onboarding`): filter endpoints (`/\/api\/(workflows|agents|scripts|config)\b/`).
- Workflows sheet exits (×, Escape, wizard Close) go `wfvRequestCloseSheet` → bare `#workflows`; only agent Delete, wizard save, Scripts delete, the shell menu and old `#agents`/`#scripts` links route `#workflows/agents|scripts`, which OPENS the Library (a ≤ 760 px overlay; a top-folder change repaints the opener away). Decide Library state explicitly; pin a 390 px row (`innerWidth` before import, `__wfv.library().isOpen()`). `__wfv.wfvOpenSheet('script', …)` is not hash-stable: use the agent pane.

## Detail tabs open from more places than `initDetailTabs`
A tab gate on anything besides UI level (git, run kind, `isGitRun`) covers EVERY opener: `initDetailTabs` `showsTab`, `reselectHiddenDetailTabs`; `setHdMode`/`setRdMode` (routes `…/details/<tab>`, level-only `tabs.activate(tab)`); the two `screen.dataset.wantTab` hand-offs (`loadHistDetailScreen`, `ensureRdTabs`); `rdActivityGroups` glance rows (`[data-rd-tab]`, also in the Chat run panel); `hdFilesChangedBox` "Open the diff"; and `activateProjTab`/`activateWsTab` (separate openers, each needs its own deep-link row). A refused gate leaves the pill `.active` with no box. Route/wantTab sites add `&& (gate || !tabs.cells.get(x).tab.<flag>)`; glance rows/links get `data-needs-git` so `:root[data-git="off"] [data-needs-git]` hides them live. `grep -n "\.activate(" ui/public/app.js` lists openers; a jsdom History boot needs a full `/api/history/:key/:id` fixture.
- Later plans count the four gated lines VERBATIM (`… needsGit)) tabs.activate(tab);`): put new logic on its own line above; add `ui-git-hide-set` to Step 4.
- A pill CLICK is not a route (`initDetailTabs` binds `activate`, `.rd-tabs` only `replaceState`s): logic in `setRdMode`/`setHdMode` never runs on a click — pin a route row AND a click row. Chrome proof: deep-link `…/details/diff`, click `[data-rd-tab="diff"]`, the active tab HAS a box.

## Refresh and Save paths
- A "refresh on broadcast" pin asserts the CONTROL, not the fetch (`workspaces-changed` refetched while `#workspaceSelect` never gained the workspace; `ensureWorkspaceOptions()` reset member branches). Probe from the view the flow leaves the user on; `refreshWdOverview` skips while the description editor is open (Save PATCHes a stale draft).
- History stubs hand out the fixture row OBJECT and `patchHistoryPr`/`finalizeHistoryPr` write `row.pr` into it (green alone, red in `npm test`): copy per response (`const { pr: _, ...row } = ROW`).
- Keyed `{[id]: def}` editors lose a row on Save (`ask.forms`; MCP form Env/Headers via `compileDefinition`): the reader returns `{meta, markdown, problems}` and EVERY caller (`saveAgentEdit`, the wizard's `saveGeneratedAgent`, both reading outside their try) refuses while `problems` is non-empty; for each reader `continue` ask what the user loses. Probe `buildAgentCard(meta)` → `openAgentEdit` → `.agent-edit-save`, stub `PUT /api/agents/<key>`; spy `row.__editor.destroy`.
- Memory editor: `load()` drops superseded loads (`if (my !== seq) return;`); "This scope changed on disk while you were editing" (from a `memory-changed` load) is the ONLY conflict guard (Save has no 409): a new load trigger needs a `frameOwed` flag.

Advanced run state with a non-default value is named in `paintHiddenSettings()` (`docs/ui-levels.md` rule 2; `state.mcpOptOut` was missing): probe `dataset.level='simple'` + `worca:level`, read `#level-hidden-note`.
- Every `applyAskPrefill` target arm AWAITS its own config reload (`setRunTarget` fires an un-awaited `onProjectChanged()`/`loadConfig('')` whose tail resets the picker); write target-forbidden state after `setRunTarget` coerced it. Pin `openNewPipeline({target, workflowId:'wf_review'})` → `#workflowSelect.value` (`ui-new-run-no-project`).
- Settings › MCP: `createMcpView` returns only `show(sub)`; reload via `mcpTab().show(location.hash.slice(1).replace(/^settings\/mcp\/?/, ''))`; the strip repaints only in `paint()`. Probe with `test/ui-team-policy.test.mjs`'s boot.
- Away form: `GET /api/away-mode` without `projectDir` answers defaults only; `field()` emits a `<label>` without `for`; `analysis` reviews EVERY question with options; `paintAwayAnswers` needs catalog readiness; `.rd-srow-tx small{…}` (0,1,1) beats a single class.
- `reportStatus(line, base, text, kind)`: `ok/err/warn/info` go to a TOAST and blank the line; only `*-inline` or no kind write it.
- Moving a Settings tab to its own view: grep every `currentView() === 'settings'` and mutate each rewrite; a mirrored `-msg` line is wiped by the loader (`loadModelsView()` → `setModelsMsg('')`, reruns on focus): probe failure, then `focus`.
