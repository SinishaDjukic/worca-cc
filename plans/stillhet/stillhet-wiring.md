One map, from the prototype's own code (the places list in `shell/shell.js`, the old-address aliases in `insights/`, `SECTIONS` in `settings/settings-model.js`). The plan is `plans/stillhet/implementation-prompt.md`. A row says where a dev feature lands, which dev data or module it reuses (data, APIs and logic only, never dev's screens), and the address that redirects with Stillhet on.
