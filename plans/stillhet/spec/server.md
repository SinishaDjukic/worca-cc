# Server work

Every piece of backend work the full Stillhet build needs, so that no page builder finds a field missing halfway
([lessons.md](lessons.md) 24). **The rule:** a wiring row may only name a route or a field that exists. One that is
missing is a row here, and it is built and merged before the page that needs it. Server work goes in its own change,
never inside a page's change, and classic is re-checked after each one (the routes are shared).

How to read "Today": **branch** is this branch (`design/stillhet-shaping`), **dev** is classic. Each was checked in the
code on 16 November (routes by grep over `ui/server.mjs` and `ui/routes/`; this branch registers 17 routes dev does
not have, dev has none this branch lacks). "Both" means the two agree.

## Not server work after all

On both. What is missing is the per-step editor in the design; S6 is the one server gap.
