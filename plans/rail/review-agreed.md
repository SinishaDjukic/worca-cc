# Reviewing Agreed: 15 cases to check by eye

`npm run rail` opens the prototype. A run case is the Prototype corner's Run picker (or `#run/<case>` in the address); Pulse cases are its Pulse picker. Check each at wide and at phone width.

1. **Run working** (Running › Working): the state word, the Stepper's live step, nothing to press but Stop in the ⋯.
2. **Run asks** (Needs you › Needs you): the question sits under its step; answer it and the run moves on.
3. **Run paused at a limit** (Paused › Paused): it says why and when it resumes; never reads as Ready.
4. **Run failed** (Ended › Failed): what went wrong in one line, the one step to take, the log one click away.
5. **Run ready** (Ready › Ready): Create PR is the one main action; Figures and Overview agree.
6. **PR checks failing** (Pull requests › Checks failing): press Fix, then Next event in the corner; the state follows.
7. **PR ready to merge** (Pull requests › Approved): Merge asks in the strip, then the page reads Merged.
8. **Feature, run 2** (Groups): each run is a segment of the Stepper; a member's row opens its run, the pager steps between them.
9. **Group shipped** (Groups › the shipped case): one PR line per run, one action left, the trail goes back to Runs.
10. **Pulse Vitals** (Pulse button, case A busy afternoon): needs you, limits, running, scheduled in that order; the sentence narrows them; nothing can be cleared.
11. **Pulse Updates and sound** (Updates tab; `New version: 1.20` is unread): in the corner press New event twice: one chime, then Pulse shows both. Turn Away on: silence.
12. **Settings menu** (profile menu › Settings, in Simple, Advanced and Expert): groups Work, AI, Access, Add-ons, Worca in that order; a group with nothing at a mode has no head.
13. **Settings search** (top bar: type `Speech`, `Copilot`, `Sources`, `Schedules`): each lands on its row with the flash, opening its fold or Dialog.
14. **A folded section** (Settings › Plugins with Labs › Ticket updates on, then General › About): Customise under Jira holds its rules; About is one row, `Version 1.19 · Up to date`.
15. **The shell** (sidebar, then narrow): every icon at one weight, the place marked; at phone width the drawer opens and closes, Settings opens on its menu, nothing runs off the page.
