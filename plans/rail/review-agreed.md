# Reviewing Agreed: 15 cases to check by eye

`npm run rail` opens the prototype. A run case is the Prototype corner's Run picker, by its group there (or `#run/<case>` in the address); the corner's Pulse picker sets Pulse's case. Check each wide and at phone width.

1. **Run working** (Running › Working): the state word, the live step in the progress, Pause as the one action.
2. **Run asks** (Needs you › Needs you): the question sits under its step; Send answer and the run moves on.
3. **Run paused at a limit** (Paused › Paused): it says why and when it resumes, with Resume now; it never reads as Ready.
4. **Run failed** (Ended › Failed): what went wrong in one line, Restart Build as its step, the log one click away.
5. **Run ready** (Ready › Ready): Create PR is the one main action; the figures and the Overview agree.
6. **PR checks failing** (Pull requests › Checks failing): Fix checks, then Next event in the corner; the state follows.
7. **PR ready to merge** (Pull requests › Approved): Merge asks in the strip, then the page reads Merged.
8. **Feature, run 2** (Groups › Feature, run 2): each run is a stage of the progress; Open run goes to it, and the pager steps between them.
9. **Group shipped** (Groups › Group, shipped): Applied, View PR, one line per PR; the trail goes back to Runs.
10. **Pulse Vitals** (Pulse button, case A busy afternoon): needs you, limits, running and scheduled, in that order; the sentence narrows them; nothing can be cleared.
11. **Pulse Updates and sound** (its Updates tab: `New version: 1.20` is unread): in the corner, New event twice with Needs you: one chime, both rows arrive. With Away on: silence.
12. **Settings menu** (profile menu › Settings, at Simple, Advanced and Expert): groups Work, AI, Access, Add-ons, Worca in that order; a group with nothing at a mode has no head.
13. **Settings search** (at Expert, type `Speech`, `Copilot`, `Sources`, `Schedules`): each lands on its row with the flash, opening its fold or Dialog.
14. **Folds** (Settings › Plugins with Labs › Ticket updates on; then General › About on a Pulse case with no new version): Customise under Jira holds its rules; About is one row, `Version 1.19 · Up to date`.
15. **The shell** (the sidebar, then a phone width): every icon at one weight, the place marked; the drawer opens and closes, Settings opens on its menu, nothing runs off the page.
