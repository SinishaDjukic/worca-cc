# Stillhet wiring: where every moved feature, action and figure stands

One map, from the prototype's own code (the places list in `shell/shell.js`, the old-address aliases in `insights/`, `SECTIONS` in `settings/settings-model.js`). The plan is `plans/rail/implementation-prompt.md`. A row says where a dev feature lands, which dev data or module it reuses (data, APIs and logic only, never dev's screens), and the address that redirects with Stillhet on.

In the app host each one answers "Not connected to Worca yet." until its area's run wires it. One row per module that holds actions here; one row per action under Action rows. Status: `wire to` (dev already has the function), `new: build it` (the design introduces it, so it is built for real; `new: built` once it is), `add to the design first` (dev has it, the design lacks it). `test/stillhet-wiring.test.mjs` fails for a module with `RailWould` calls that has no row here.
