# R7 · Dana: verdict on r6-ux

**Pass. It's faster for me.** I type into menus, I don't scan them, and a short menu with a find field at the top is the best case for that.

- **A model I rarely use:** open the engine menu, type "gem", Enter. Same speed as before, as long as the top find searches *every* engine (nit 1).
- **Effort behind Thinks ›:** type "deep" or "high" in the engine find, Enter. One step, no submenu. With arrows it's one › more, which I can live with.
- **Repos:** my 3 repos are always in the top 5, so no change there.

## Nits

1. **The top-level find in the engine menu must search Other engines too.** Typing "gemini pro" at the first level should find it without opening ›.
2. **Keep the 3 recent models in a stable order** (for example by family, then name), not reshuffled after every pick, so ↓↓ Enter always lands on the same model.
