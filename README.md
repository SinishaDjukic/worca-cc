# worca-policy

This branch carries the team policy Worca reads for this repository (`.worca-policy/policy.json`): cost caps, expected plugins, model and guardrail defaults. Edit it from Worca's Team policy page or by pull request. Protect this branch so only maintainers can push; every teammate's Worca reads it. To turn the policy off for the whole team, delete this branch: `git push origin --delete worca-policy`.
