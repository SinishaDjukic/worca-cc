## 0. Summary

PR #359 (222 files, +26k/−11k, 217 commits behind, CONFLICTING) implemented the node-graph concept and rotted on a long-lived branch. It is discarded. The **concept stays** (typed ports, wires, derived loops with per-wire budgets, Task/End/AND/OR/Combine flow cards, universal `await` gate, generic engine, A1–A4 v1 parity). The **implementation restarts on current dev** as eight sequential plans, each leaving the suite green and dev shippable, with the v1 engine live until the final cut-over.

Three structural corrections over PR #359:
1. **One source for the graph model** — `src/shared/graph/` pure ESM imported by server, tests AND browser (no build step; relative imports that walk above the static root; served at `/src/shared`). PR #359 byte-copied 700 LOC into the browser.
2. **A canvas engine built for smooth dragging** — stage-owned pointer capture, rAF-coalesced frames, incremental DOM updates, ghost cord in the same SVG layer with structural `fill:none`, zero layout reads on the move path, no on-canvas controls. PR #359 re-validated and re-rendered the whole graph per pointermove.
3. **Coexistence by data, not by flag** — the engine is chosen by the template's `version` (or the resume point's), a harness base class serves both engines, and a `phase` shim lets v2 runs render in the untouched UI until the monitor plan lands.

## 3. Shared graph core (`src/shared/graph/`)

**Why**: the engine, the server's 422 path, the composer's live validation, the run monitor's geometry and the thumbnails all need the same model. PR #359's byte-copy policy (`old:ui/public/graph/graph-model.mjs:5-14`) was its deepest flaw.

**Location**: `src/shared/graph/` — below both `src/core` (Node-land) and `ui/public`; neither layer imports the other. Both `src/` and `ui/public/` are in `package.json#files`.

**Serving (no build step)** — insert after the `/vendor` tail at `ui/server.mjs:769`, before the `express.static(PUBLIC_DIR)` mount at `:771`:
```js
// src/shared/** is the ONE source of the graph model for server + browser
// (no build step). ui modules import it by relative path that walks above
// ui/public; the browser clamps that URL at '/', so it must be served here at
// exactly the repo-relative path. The 404 tail keeps a typo'd path from
// falling through to the SPA index.html (which Chrome reports as a MIME error).
const SHARED_DIR = path.join(PROJECT_ROOT, 'src', 'shared');
app.use('/src/shared', express.static(SHARED_DIR, {
  index: false,
  setHeaders: (res) => res.set('X-Content-Type-Options', 'nosniff'),
}));
app.use('/src/shared', (_req, res) => {
  res.set('Cache-Control', 'no-store');
  res.status(404).type('text/plain').send('Not found');
});
```
Verified 2026-08-26 (agent B probe): express 4.22.2 → send → mime 1.6.0 serves `.mjs` as `application/javascript`; Chrome 151 executes it as a module; `..` above the URL root clamps so `../../../src/shared/graph/x.mjs` from `/graph/composer.mjs` resolves to `/src/shared/graph/x.mjs`; Node, jsdom and Chrome all receive ONE module instance for the same file whether imported with 2 or 3 `..` segments; `?b=` cache-busting of `app.js` does not re-evaluate shared deps.

**Import convention** (the `..` count = the importing file's depth below the repo root; every ui module carries a one-line header comment saying so):
```js
// ui/public/app.js                (depth 2)
import { portsFnFor } from '../../src/shared/graph/ports.mjs';
// ui/public/graph/composer.mjs    (depth 3)
import { validateGraph } from '../../../src/shared/graph/validate.mjs';
// src/core/graph/scheduler.mjs, ui/server.mjs, test/*.mjs — ordinary relative paths
import { classifyLoops } from '../../shared/graph/loops.mjs';
```
Absolute specifiers (`/src/shared/...`) are FORBIDDEN (they break Node ESM: UI tests import `ui/public/*.mjs` as plain Node modules, e.g. `test/composer-ui.test.mjs:7-16`, `test/ui-composer-wires.test.mjs:15-31`). No import map.

**Purity rules** (guard test `test/shared-graph-purity.test.mjs`, code in `adj-b.md` §5): every file under `src/shared/**` uses only relative imports that stay inside `src/shared`; no `node:` builtins, `require`, `process.`, DOM globals, `fetch`, `import.meta`, or top-level `let`/`var`; every `ui/public` specifier that leaves the static root lands inside `src/shared` at a URL equal to its disk path. Companion `test/api-shared-static.test.mjs`: every shared file GETs 200 `application/javascript` + nosniff with body == file; `/src/shared/graph/nope.mjs` and `/src/shared/graph/` → 404 `text/plain` (never `text/html`).

## 4. Template schema v2 and storage

Template shape (flat; base spec §1 as amended): `{ id, name, version: 2, domain, origin?, nodes: Node[], wires: Wire[], canvas?, createdAt, updatedAt, archivedAt? }`. Node `{ id, kind, key?, x, y, config: { model?, effort?, fanOut?, askQuestions?, awaitAll?, arity?, planStoreSeed? } }`; wire `{ id, from:{node,port}, to:{node,port}, config?: { maxCycles? } }`. Ports are never stored (from sidecar meta / engine flow ports). `canvas` is accepted and ignored (auto-fit replaces viewport persistence).

**Storage** (`workflows` table): `graph TEXT` holds `{nodes, wires, canvas?}` only (id/name/domain/origin stay row columns — no drift on rename); `archived_at TEXT` (`NULL` = live). v2 rows write `version = 2, steps = '[]', feedbacks = '[]'`. `rowToTpl` (`workflows.mjs:206`): base fields; `version === 2` → `+{nodes, wires, canvas?}` from `graph`; else `+{steps, feedbacks}`. `writeWorkflow(tpl)` stays v1; new `writeGraphWorkflow(tpl)` (UPSERT; saving over an archived id un-archives). `listWorkflows({includeArchived = false})` → `WHERE archived_at IS NULL`, both versions returned with `version` visible. `readWorkflow(id, {includeArchived = false})` → `null` when archived. New `assertRunnableWorkflow(id) → template` throwing `{code:'NOT_FOUND'|'ARCHIVED', message}` used by `POST /api/run` (`ui/server.mjs:1062`), CLI `--workflow`, `ask/proposal.mjs:104-106`; ARCHIVED message: `workflow "<id>" was archived by the v2 upgrade (v1 template, not runnable) — pick a v2 pipeline or rebuild it in the Composer`. `GET /api/workflows/:id` calls `assertRunnableWorkflow` and maps `NOT_FOUND`/`ARCHIVED` to 404 with `e.message`; `GET /api/workflows?archived=1` returns ONLY archived rows (composer shows an "Archived (N)" footer with delete). `writeGraphWorkflow({ id?, name, domain, origin?, nodes, wires, canvas? })`: `id` = `body.id` when it matches `SAFE_WORKFLOW_ID` and is not `wf_default`/`wf_default_v2`, else `wf_${slugify(name)}` (`workflows.mjs:242`); the composer's Save on a loaded row sends its id, Save-as omits it. `deleteWorkflow` and `removePluginWorkflows` unchanged (they also delete archived rows).

### 5.3 Scheduler (`src/core/graph/scheduler.mjs`, pure, IO-injected)

`createScheduler({ template, portsFn, loops, execute, onEvent, onSnapshot, onGate, onAsk, maxParallel, log }) → { run(), pause(), abort(), reattach(snapshot), getState() }`. Owns: token latches per output port (`{seq, type, path, value, meta, firedAt, sourceExecutionId, forced}`, global monotonic `seq`), `consumed['<node>.<port>'] = seq`, readiness per base spec §3 as amended (Task fires once; End/AND/Combine all-fresh; OR any-fresh binding the freshest and re-emitting its payload with a new seq — one emission per drain; agent first run waits on every wired non-loop input incl. `await`, loop inputs excused; re-run on any fresh token, or with `awaitAll` on all wired non-loop fresh OR a lone fresh loop token), deterministic launch order (condensation-topo, nodeId), a semaphore for agent executions (`WORCA_MAX_PARALLEL`, default 4; flow executions bypass it and fire at their order slot, never eagerly at publish), `rerunPending` one-shot coalescing, per-wire `{ deliveries, allowance = maxCycles − 1 }` (A1) with the human gate at the would-be `maxCycles`-th delivery (`another` → allowance += 1 and deliver; `continue` → discard the held token and force-fire the source's clean outputs with the A4 payload rule; gate ask id `gate-<wireId>-<deliveryNo>`, payload `{ id, kind:'gate', wireId, nodeId: fromNode, executionId, issues }`, answered through the unchanged `POST /api/answer {id}` path; non-interactive runs answer gates with `continue` and clarify asks with `[]` — the v1 `_ask` auto path), End drain (`ended = {nodeId, executionId, seq, result}`: stop launching, in-flight executions publish and latch but route nowhere, pending asks withdrawn with empty answers, loop-delivery/gates skipped, agent error still fails the run), quiescence detection (`'done'` + `endReached:false` warning when no End token), fail-fast (first genuine execution error aborts in-flight siblings), snapshot after every publish and at finish, `reattach()` re-invoking `execute` for every non-terminal execution with its RECORDED args.

Composite fan-out is driven by the scheduler: a fresh token binding an `expands` input (and no fresh loop trigger) runs `execute` with `composite:'expand'` → `{phases}`; then per phase: `execute({composite:'phase', phase, phaseStatus:'running'})` (returns `{}`), the phase's slices `execute({kind:'task', slice:{id, title, phase, path, index, siblings:[{id,title,file}]}})` in parallel under the semaphore with sibling-failure abort, then `execute({composite:'phase', phase, phaseStatus:'done'|'error'})` (returns `{}`); finally `composite:'finish'`; the node's outputs fire ONCE. `trigger.freshPorts` = the bound ports whose token seq > consumed seq (on a first execution: every bound port except `await`); `trigger.wireIds` = the wires that delivered them. A later fix re-fire runs a single normal execution. Execution ids: `x:<nodeId>:<ordinal>` and `x:<nodeId>:<ordinal>:p<P>t<T>` (`sliceExecutionId`).

Snapshot: `{ version:2, seq, graph, tokens, outputs, consumed, ordinals, wires:{[wireId]:{deliveries, allowance}}, ended, execs:[{executionId, nodeId, kind, ordinal, status, sessionId, taskId?, expandsPort?}], gates:[{wireId, nodeId, executionId, token, issues}], asks, gate, ask }`.

### 7.3 Pointer pipeline (normative)
Listeners bound in `mount()`, removed in `destroy()`: stage `pointerdown/pointermove/pointerup/pointercancel/lostpointercapture`; window `blur` → cancel (+ space=false); document `keydown/keyup` (the `isTyping(ev.target)` guard runs BEFORE any key handling; Escape cancels the gesture, else clears selection); stage `wheel {passive:false}`; `ResizeObserver(stage)` (guarded), window `resize`, document `scroll {capture:true, passive:true}` refresh the cached stage rect.

- `onDown`: reject if a gesture is live or `button ∉ {0,1}`; ONE `readRect()` (cache `{left, top, width, height}`); `pt = toWorld(clientX, clientY)`; classify: middle button or space ⇒ pan; `hitPort` ⇒ wire gesture (ghost shown now, one write); `hitNode` ⇒ node gesture (grab offset, start position for cancel-revert, `moved=false`); `hitWire` ⇒ select wire; else pan + clear selection. Then `try { stage.setPointerCapture(pointerId) } catch {}` (synthetic ids throw; jsdom lacks the method — capture is a bonus, never a precondition) + `preventDefault()`.
- `onMove`: `pend = {clientX, clientY}; if (!raf) raf = requestAnimationFrame(frame)`. NOTHING else — no DOM, no hit-test, no validation.
- `frame()` (≤ 1 per animation frame): pan → one transform write; node → `nx = snap(pt.x − grab.dx)`; if unchanged return; update the model, `placeCard` (one transform write), `paintWire` for `incident.get(id)` ONLY (the `d` cache prevents identical writes); wire → `hitPortAt(pt, origin)` (nearest port within 14px), `canWire(…)` (a Map lookup on the wired-input set + a type check — no `classifyLoops`, no Tarjan), one ghost `d` write + class, chip show/hide.
- `onUp`: cancel the pending rAF, run `frame()` once with the up position, then commit (wire drop → `commit()` if legal; node drag → one undo entry if `moved`), then `finish()` = clear gesture/pend/raf, hide ghost + chip, `releasePointerCapture` (guarded by `hasPointerCapture`). `cancel()` reverts a moved node to `start`, hides the ghost, `finish()`.
- Validation and `classifyLoops` run once per COMMITTED mutation inside `commit(label, mutate)` (push undo → mutate → dirty → targeted render → `scheduleValidate()` via `setTimeout(0)`, collapsed to one run). Never per frame; `render()` never runs on the pointer path. Zero `getBoundingClientRect` calls per move (one per gesture start, one per `fit()`, plus observer-driven refreshes).

## 13. Risks

1. P1's harness move touches the live engine — mitigated by the byte-identical mandate and the 53-importer test oracle; land it alone.
2. Coexistence churn (dual-shape sidecars, shim, alias) adds temporary code — bounded by P8's grep guard and the explicit kill list.
3. Prompt-byte regressions — the parity pin list is the contract; the single-directive rule and three token substitutions are the only generic machinery.
4. Tools regression (frontmatter grants) — pinned for manualWebUiTesting.
5. Loop cascades re-run the downstream cone per iteration — inherent; bounded by wire allowances + per-launch cost gate.
6. V24 archives every v1 row — reversible (rows kept, `.pre-v24.bak`), audited, and the 7 seeds cover the known shapes.
7. Wheel capture on detail pages — engaged-only policy; verify page scroll is never trapped.
8. Old-branch borrowing — every borrowed file must be re-verified against dev anchors (the §6 drift list), never pasted blind.
