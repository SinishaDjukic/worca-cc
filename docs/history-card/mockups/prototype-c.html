Prototype C — the ledger

The dense repair: history is a ledger, one surface — rows in a single card separated by hairlines, like a GitHub PR list. Status compresses to a tinted icon, freeing the row to be two lines tall. Facts that used to float in odd corners (plugin source, PR state, pause reason) all become inline tags after the title — one place, one shape. The meta line absorbs the branch pair, so a row never grows a third line.

  • one card, hairline rows
  • status = tinted icon, not a pill
  • PR state, provenance, pause reason = title tags
  • meta + branch pair on one mono line
  • square-ish buttons, uniform
