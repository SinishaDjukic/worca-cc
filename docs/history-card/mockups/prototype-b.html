Prototype B — one primary action

The opinionated repair: a row earns at most one real button — the single next step for that pipeline (Resume beats Create PR when paused). Everything else moves into a ⋯ overflow menu (Create PR while paused, Archive, Copy branch, Report result). Status leaves the pill entirely: a colored edge stripe plus a dot-word on the meta line carry it, which frees the whole left column for the title. This is the Linear/Vercel list-row idiom.

  • status = edge stripe + dot-word, no pill
  • exactly one primary button per row
  • secondary actions behind ⋯
  • pause reason inline with the status word
  • branch pair: source → feature
