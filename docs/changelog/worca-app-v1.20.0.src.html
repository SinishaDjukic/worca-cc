Runs

Run time reads like a clock.

Why did a ten-minute run say forty minutes?
Now the run time moves one second per second, counts parallel work once, and stands still while the run waits for you. The sum of every agent's time has its own tile.

Tickets

Your ticket hears about every run event.

Did the ticket say "done" while the PR was missing?
Now Worca comments on the run's ticket when it starts, needs you, fails, finishes and opens its pull request. The finish comment says whether a PR is open. Only that comment moves the ticket.
