Terminal

One terminal for you and Ask.

Want to step in while Ask is working?
Now Ask's commands play live in the terminal pane. Type in the same tab, then tell Ask "continue": it sees what you ran and picks up from there, in the same shell.

your cd and venv carry overclick a command to open its tabnever takes your keyboardnever stops your commands

Your own commands never interrupt Ask; your next message tells it what you did.

Restarts

Stopping Worca pauses runs safely.

Ever restarted a server and lost a run halfway through?
Now a stop pauses every active run at a point it can resume from, refuses new runs, and then exits. You can also have paused runs resume on their own when Worca starts again.

on every installalways finishes stoppingresume on start, if you want it
