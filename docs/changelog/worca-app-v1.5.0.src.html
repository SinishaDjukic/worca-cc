Install

Run Worca in a container.

Rather not give agents your whole laptop?
Now Worca and every agent it starts can run inside a disposable Linux container. One command sets it up; add-ons lock down the network, lend your SSH key or open it to the team.

1 command to set upIntel and Apple siliconsigned imagesruns on Railway
Set up once, then run
$ worca container init --projects ~/dev
$ worca container up
$ worca container login
$ worca container run -- --prompt "…"

Your projects are mounted; your home folder is not.
