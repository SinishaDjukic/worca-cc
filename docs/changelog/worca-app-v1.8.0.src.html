Terminal

A terminal in every run's folder.

Want to poke at what an agent just built?
Now a terminal opens right in the run's folder: a live run's worktree, a finished run's checkout, or your project. Hide the pane and the shell keeps running. A new Actions tab runs your project's own commands, like Test or Dev server, with live logs.

CLI

Stop and follow runs from the CLI.

Working in the terminal and need to stop a run?
Now worca stop, worca pause and worca resume take any run by the start of its id, even with the web UI closed. worca logs -f follows a run's live log.
