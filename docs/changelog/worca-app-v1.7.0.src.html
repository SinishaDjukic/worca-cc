Branches

Every run starts from the latest code.

A run built on a branch three commits behind?
Now Worca fetches before a run starts and brings your branch up to date when that is safe. It never merges, rebases or resets your work: if your branch and origin have both moved, it asks first. Projects and workspaces show where every repo stands.
