Marketplace

Find, install and set up plugins.

Not sure what a plugin adds, or what it needs before it works?
Now the Marketplace page shows every plugin grouped by what it adds. Installing one opens a sheet: review what it adds and the secrets it asks for, install, then fill in its settings straight away. The Installed tab puts plugins that still need setup first, and updates are reviewed one at a time.

Runs

Runs that name themselves.

Tired of runs called after the first words of a long task?
Now, with Smart run naming on, a small model reads the task as you type and suggests a short title and a branch name in your team's style, like feat/rate-limit-contacts-search. Change the type and the branch follows. Type over either field and Worca keeps your words.

Shaper

Shaper is on for everyone.

Missed Shaper because it was hidden in Labs?
Now Shaper, which plans a task with you before anything is built, is in Beta and switched on. Pick it on the Chat home, describe the problem, and approve the plan before a run starts. If you had turned it off, it stays off.

Projects

Turn a folder into a git project.

Want branches and pull requests for a plain folder?
Now press Use git on a Folder project. Worca sets up git in place, links a remote if you give one, and the project gets its sync bar and Branch card without a reload. A git project with no remote gets Link remote instead.

Reliability

Bug fixes and security updates.

Lost a run’s work to an interrupted git command?
Now Worca clears the lock files a killed git command leaves behind, so a run still saves its work. Show in folder opens the project's copy when a run's own folder is cleaned up. Three libraries got security updates, and 1.13.1 fixes the New run form saying "Run not started" for a run that had started.
