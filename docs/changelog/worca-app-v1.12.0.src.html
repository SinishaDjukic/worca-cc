Shaper

Plan it with Worca before it builds.

Ever had a run build the wrong thing because the task left too much open?
Now Shaper asks up to 3 questions, writes a plan, has it checked by a reviewer for each role you pick, and builds only once you approve. A task too big for one change is cut into slices, each with its own branch and pull request.

Presets

Save a setup. Start from it.

Setting the same workflow, models and tags for every client run?
Now save a New run setup as a preset and pick it next time: the run gets the preset's choices, and the project's settings stay as they are. Presets sit as chips on the Chat home, schedules follow them, and worca run --preset starts one from the terminal. Schedules can also run several times a day.

applies to this run onlyone click from the Chat homeschedules from every 15 min

Projects

Any folder can be a project.

Not everything you want changed lives in a git repository?
Now add any folder as a project. Runs work on a copy, and you review the changes and choose Apply to folder or Discard. A run can also have no project at all, and the workspace wizard imports repositories, whole folders of them and .code-workspace files.

Reliability

Runs that look after themselves.

Came back to a run stuck on a dropped network, or a branch that no longer merges?
Now a run paused by a network drop resumes on its own when the connection returns. A finished run is checked against its base branch, and when the base moved or conflicts, Update branch or Resolve fixes it from the run page. Watch PR fixes report into the chat that opened the pull request.
