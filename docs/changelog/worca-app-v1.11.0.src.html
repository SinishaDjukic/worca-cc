Chat

Chat is the new home page.

Tired of switching pages to start a run, answer it and check on it?
Now Chat opens first. Ask in plain words, OK the run Worca proposes, and follow it in a live card: answer its questions, pause or stop it, and open its pull request, all without leaving the conversation.

answer a run's questions in the chatundo for every change it makesthe full run page beside the chatattachments up to 100 MB
From a question to a pull request
  1. 1Ask: the contacts search is slow, can you page it?
  2. 2Worca proposes a run, and you press OK
  3. 3The run card answers, pauses and stops in place
  4. 4Open run puts its full page beside the chat
  5. 5Create pull request, straight from the card

Tool output and commands stay folded until you open them.

Watch PR

Worca keeps its pull requests green.

Opened a pull request and came back to red checks, a conflict and review comments?
Now tick Watch PR. When a check fails, the branch conflicts or a reviewer asks for changes, Worca starts a fix run on the pull request's own branch and pushes the fix.

GitHub and Azure DevOpsskips checks that fail on dev toore-runs a flaky check onceat most 3 fix runs
A check fails: what Worca does
  1. 1Fails on dev too? Not this pull request's fault: leave it
  2. 2Might be flaky? Re-run it once
  3. 3Behind dev, and dev passes? Merge dev in first
  4. 4Still red: a fix run with the failing log
  5. 5The fix is pushed and the pull request updates

Stuck after three tries? It stops and tells you.

Architecture

A workflow that draws your architecture.

Is your architecture diagram older than half the code?
Now run Architecture (C4): Worca reads the codebase, writes or updates a C4 model of it, checks the model, and renders it. Click any box to light up what it calls and what calls it.

creates or updates the modelworkspaces with several repositoriesSVG, JPEG and PNGfull screen in Artifacts

Worca's own model: Engine adapters selected, its links lit up.

The Architecture (C4) workflow
  1. 1Discover: finds an existing model, or none
  2. 2Setup: you pick update or create, and how to group
  3. 3Architect: writes the model from the code
  4. 4Check: sends problems back to the architect
  5. 5Render: SVG and images, where you asked

Images come from a browser already on your machine, no extra install.
