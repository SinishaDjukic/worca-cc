The box it runs in

No Bash. No Read. No Write. The assistant is spawned with the Task tool and worca's own MCP server, and nothing else — the file tools do not exist in the process.

Guarded files never reach the model. Any diff section touching a protected path is dropped before the answer is written, rename-aware. Secrets are redacted on the way out, and permissive guardrails are always refused.

Turn caps — 40 turns, $2, 15 minutes — live in Settings → Ask Worca and are read fresh every turn.
