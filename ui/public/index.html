    Connect Claude Code
    
          
        
    
        
    Worca drives the Claude Code CLI. Real runs need it on your PATH; mock runs need nothing.
    
        
    npm install -g @anthropic-ai/claude-code
    
        
    On native Windows the native installer works too. A binary elsewhere: set WORCA_CLAUDE_BIN to its full path and restart the UI.
    
        
    Then sign it in. Start it once in a terminal and type /login:
    
        
    claude
    
        
    Signing in to the Claude desktop app does not carry over — the CLI keeps its own sign-in.
